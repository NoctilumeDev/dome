# 图书馆助手能力合同 v2

模型解释开放语言；本地验证有限能力；用户可以观察、确认和纠正解释。本文替代旧的“本地猜测的查询类型优先于模型”及通用语义兜底合同。

## 能力与身份

公开馆藏：搜索、作者/分类检索、可借状态、位置、馆藏排序推荐和总览；公开书评：按书名查询。
个人能力：当前会话自己的借阅、即将到期、书评、反馈。管理员、老师、其他业务角色遵循同一助手边界；全局用户、他人借阅/反馈、审批和修改仍由工作台处理。

模型只输出一个 `QUERY / CLARIFY / REJECT` 对象，十三个必需字段：`action,intent,title,author,category,publisher,keywords,availableOnly,unreturnedOnly,timeOption,days,limit,reason`。不接受用户 ID/用户名、SQL、接口地址、任意字段、多个对象或动作数组。JSON 重复字段、类型和范围错误在执行前拒绝。

| 能力 | 实际支持的条件 |
| --- | --- |
| 公开馆藏 | 书名、作者、分类、出版社的字面包含；最多三个关键词匹配任一（书名/作者/ISBN/出版社/分类/简介）；可借数量大于零或不大于零 |
| 本人借阅 | 书名包含、仅未归还；不能筛借阅日期或仅已归还 |
| 本人即将到期 | 书名包含、未来 1–30 天内未归还且到期；由执行时服务器 Clock 计算 |
| 公开/本人书评 | 书名包含 |
| 本人反馈 | 无附加筛选 |

每次返回 1–50 条，匹配总数与截断另行展示。所有已声明的条件完整执行，做不到则 `CLARIFY/UNSUPPORTED_FILTER`，不删条件后扩大查询。未知书名保持字面搜索、可返回空结果；不会变成全馆查询。模型没有声明的遗漏无法由能力校验自动发现，不能宣传语义绝对正确。

## 查询与确认

开放表达的个人计划先返回 `CONFIRM_SCOPE`：不读取个人记录，展示真实执行范围（包括不按日期/书名/归还状态筛选的部分）。确认绑定当前 JWT 会话摘要、用户、计划快照、五分钟有效期和一次性令牌；只执行显示过的同一计划，不再次调用模型。任何新请求使同一会话的旧确认失效，迟到计划不能覆盖新请求。确认入口重新经过现有 JWT/账号状态校验。

公开查询直接执行并展示解释。完整标准命令“我的借阅记录”“我借了哪些书”“我的反馈”“我的书评”“馆藏总览”“有哪些馆藏”“查《书名》”“《书名》放在哪里？”可直接执行；包含其他历史/条件/子句时不适用。没有模型或超时/繁忙时，其余表达只澄清，不猜备用业务查询。外部完整响应限时五秒、每账号一个模型请求、全局四个，无自动重试。

寒暄/元问题和一个业务动作可共存。明确要求忽略、无视或绕过限制、索取凭据或写操作时整条拒绝，不调用模型，也不执行夹带的合法查询。第一道领域规则只是入口，不能被描述为完备语义分类器。

## 维护和证明边界

`mvn package`、`npm test`、`npm run build` 与 `.github/workflows/library-ci.yml` 守有限能力、固定 SQL、本人隔离、条件保留、确认和现有工作台权限。真实模型实验另记候选 SHA、冻结问题表、相同夹具和参数；语义质量不是权限安全，也不是默认 CI 的满分目标。

确认存储是单实例内存，最多一千个会话，重启令牌失效；未证明多实例共享确认或生产容量。托管服务/H2、MockMvc、浏览器演示不冒充真实 MySQL/生产浏览器/所有自然语言路径资格。阶段退出只保留原反例、最终见证及仍有消费者的材料，临时 Key 不进入源码或证据。
