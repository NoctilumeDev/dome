高校学生宿舍管理系统 · 功能模块图

宿舍管理系统（简化版）

1. 用户与会话

  • 新生注册（固定为学生身份）
  • 登录 / 退出（Session 会话保持）
  • 三类角色：管理员、宿舍管理员、学生
  • 管理员查看用户列表、添加用户
  • 密码使用 BCrypt 摘要保存
  • 前后端按角色限制页面和接口权限

2. 宿舍资源管理

基础数据（仅管理员增改删）

  • 宿舍楼增 / 改 / 删
  • 楼层增 / 改 / 删，归属楼栋
  • 宿舍增 / 改 / 删（宿舍号、容量、生活特点）

床位管理（管理员 / 宿管）

  • 床位新增 / 编辑 / 删除（带引用校验）
  • 选择学生，为其分配空床位
  • 分配前检查学生和床位，避免重复入住
  • 床位腾空：解除占用、恢复空闲
  • 状态切换：空闲 / 已占用 / 维修中

3. 入住管理

  • 学生选择氛围、作息、卫生和兴趣偏好
  • 按固定分数推荐最多 3 个有空床的宿舍
  • 学生可采用推荐，也可自行选择意向宿舍
  • 推荐只供参考，不自动审批或决定床位
  • 学生提交入住申请（选择意向宿舍、填写原因）
  • 学生只查看自己的入住申请
  • 管理员 / 宿管查看偏好后审批：通过或驳回
  • 通过后自动匹配空床位并完成分配
  • 已有床位或待审核申请时不能重复提交

4. 退宿管理

  • 学生从自己的当前床位中选择并提交申请
  • 学生只查看自己的退宿申请
  • 管理员 / 宿管审批：通过或驳回
  • 审批通过后床位自动腾空、恢复空闲

5. 维修报修

  • 学生提交报修单（位置、故障描述）
  • 学生只查看自己的报修单
  • 管理员 / 宿管受理：待处理 → 处理中
  • 管理员 / 宿管完成：处理中 → 已完成
  • 记录处理人与处理时间

6. 水电费账单

  • 管理员 / 宿管按月录入水费、电费、其他费用
  • 系统自动合计应缴总金额
  • 学生查看本人月度账单
  • 演示性缴费：未缴 → 已缴

7. 公告通知

  • 管理员 / 宿管发布公告（标题、正文）
  • 发布范围：全体 / 指定楼栋
  • 记录发布人与发布时间
  • 学生查看全体公告和本楼栋公告

8. 数据看板

  • 床位总数 / 已占用 / 空置 / 维修中统计
  • 整体入住率
  • 分楼栋入住率一览
  • 待处理入住、退宿、报修数量
  • 本月入住、退宿申请数量统计

本项目采用 Spring Boot + MySQL + 原生 HTML/CSS/JavaScript，曾作为本科毕业设计候选方向进行本地演示。
