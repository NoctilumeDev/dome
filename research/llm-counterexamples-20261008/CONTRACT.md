事前冻结 24 道当前合同标签题（六族、两变体、两系统）及 8 道 DuSQL 开发集原文。外部原文按域与 SQL 运算条件筛选后固定种子抽样，原 SQL 需要当前产品不支持的字段/运算，执行标签由本轮执行者映射为 CLARIFY。它们单列能力边界分布，不充当独立真人标注，也不与作者题混成总体准确率；原数据来自官方非商业研究发布，全集不提交。

每题四次重复，每块两厂商各四个独立调用及四个审查，128 块/1,536 请求。A–F、结构规范化、完整字段资格与原生 v2 评分不改；所有 PA/PB 固定复用，不再生成替代答案。温度0、thinking关闭、期限5秒、无自动重试，模型别名与旧层一致。执行上独立的请求不被称作统计独立采样。

自然分布报告 A对/B对、A对/B错、A错/B对、A错/B错；一致/分歧分别报告模型计划正确性与原生资格。P(正确|分歧)拆成 A 正确、B 正确、至少一方正确，不能凭空选择最终答案。共同遗漏只是按事前失败族/字段差异可复算的标签，不宣称完成人工语义审核。

联合错误与独立边际乘积按全表及逐题分别报告。主要探索量为逐题平均的 observed joint minus pA*pB；同题内置换 B 的重复顺序形成保持边际的零分布，按题族整体 bootstrap 4,000 次。题目难度、有限重复、模型别名与时段仍是边界；不作普遍误差依赖或确认性显著性结论。

自然 B 与 C/D 只衡量：新增阻断 B 已放行错误、正确 QUERY 被阻断、正确 CLARIFY 再澄清、弃权、逻辑成本/延迟。正确非 QUERY 的非 ACCEPT 不统一算误杀。多数 F1/F2/F3/F4 报告正确计划、公开执行、范围确认、弃权、错误集中度、完整计划熵及同类失败频率；熵是四样本的经验量，单样本熵0不是可信度。

另有固定错误审查试验：八个事前题目各一份完整正确计划及一份完整错误计划，两个审核者各重复三次，96 请求。人为设置 PA=PB，先验证原生能力资格，再看审查能否发现错误。此试验专门给 reviewer 发现一致错误的机会；不能伪装成真实两模型自然达成一致，不能估计自然错误发生率，不混入自然结果分母。
