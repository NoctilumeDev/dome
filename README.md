下课了。我们接着把它弄明白。

## 原来的两个项目

`coursework/` 和 `independent-projects/` 里的两个项目，已整理至可运行、可形成基本功能闭环的状态，但保留其当时的工程形态，不按后续项目标准重构，也不补造不存在的开发历史。

根据仓库作者现场监督的复现记录，两个项目均由豆包在其 Linux 沙箱环境中完成构建、启动、核心 CRUD 与业务闭环验证；在该次复现场景中未发现关键写操作的一致性异常。
