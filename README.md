# dome

`dome` 不是拼写错误。

本仓库保存本科阶段课程作业、独立项目及相关文字记录。项目均整理至可运行、可形成基本功能闭环的状态，但保留其当时的工程形态，不按后续项目标准重构，也不补造不存在的开发历史。

两个项目均已在 Linux 环境完成复现，核心 CRUD 与基本业务闭环可以运行；在当前复现场景中未发现关键写操作的一致性异常。

**史书会告诉你：“那年，计算机教育蓬勃发展，中国高等教育蒸蒸日上。”这个仓库只负责保存当年的证据。**

## 内容

- `coursework/`：课程作业
- `independent-projects/`：独立项目
- `writing/`：文字记录
