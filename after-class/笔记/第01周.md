# 第一周：先让浏览器回句话

我就想试一件事：我在 Java 里写一句“你好”，浏览器能不能看见？

项目已经准备好了，先运行：

```bash
mvn spring-boot:run
```

等终端里出现 `Started CourseApplication`，浏览器打开：

<http://localhost:8080/hello>

如果看到“你好”，行，第一件事已经成了。

第一周的完整代码是这样：

```java
package com.example.repair;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController // 给 Spring 留个记号，不然它不知道这里能回话
public class HelloController {

    @GetMapping("/hello") // 还得写清楚地址，Spring 才知道 /hello 该找谁
    public String hello() {
        return "你好"; // 把这句话交给 Spring，再送回浏览器
    }
}
```

上面的 `package`、`import`、`class` 都有自己的作用。现在先不解释，不是因为它们不重要，只是这周想先把浏览器和 Java 的第一句话接上。先让它们待在该在的位置。

这次先看那两个 `@`。

你把“你好”写好了，可项目里还有别的代码。浏览器找过来，Spring 得知道该去哪里找这句话。

就像办事大厅里坐了一排人，窗口没牌子，你也不知道该找谁。

所以才有上面那两行：`@RestController` 先告诉 Spring 这里有人接待，`@GetMapping("/hello")` 再写清楚，来找 `/hello` 的交给这里。Spring 又不会读心，得给它留个记号。

里面干的活现在只有一句：

```java
return "你好";
```

就像窗口里的人说“办完了，给你这个”。Spring 接过去，再交给浏览器，你才看见了“你好”。

不信就把那句话改成：

```java
return "我居然跑起来了";
```

[重新运行](第00周.md#rerun)，再打开网页看看。

刚才改了 `return` 后面的话，浏览器里的字也跟着变了。

不过，这句话是我们写在 Java 里的。谁打开这个地址，看见的都一样。

要是想让张三看见“你好，张三”，李四看见“你好，李四”，总不能来一个人，就回去改一次代码。

那能不能让浏览器把名字一起带过来？

先留着这个问题。下周我们试试。
