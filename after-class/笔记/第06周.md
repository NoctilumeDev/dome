# 第六周：让 Java 去 MySQL 找

上周最后问，Java 能不能去 MySQL 里，把留下的那条报修找回来？

试一下。

先打开 `src/main/resources/application.properties`。用户名不是 `root` 的，把第二行换成自己的；最后一行换成安装 MySQL 时设置的密码。真正的密码只留在自己电脑上，别提交到 GitHub。

按前面的方法[重新运行](第00周.md#rerun)，再打开：

<http://localhost:8080/repair?id=1>

浏览器里会出现：

```json
{
  "id": 1,
  "room": "3-412",
  "content": "水龙头一直滴水"
}
```

“水龙头一直滴水”这句话，现在没有写在 Java 代码里。它是第五周留在 MySQL 里的。

Java 真的去找回来了。

`Repair.java` 这周没改。新添的 `RepairMapper.java` 是这样：

```java
package com.example.repair;

import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Select;

@Mapper // MyBatis 看到这个记号，才会来接这份活
public interface RepairMapper {

    @Select("SELECT id, room, content FROM repair WHERE id = #{id}")
    Repair findById(Long id); // 给它一个编号，它会交回来一条 Repair
}
```

`interface` 也是第一次见。它不是不重要，只是今天先看 Mapper 怎么拿着 SQL 去 MySQL，名字和规矩以后再说。

先看中间那句 SQL。第五周已经写过 `SELECT`，这次只是多了 `WHERE id = #{id}`。

浏览器带来 `id=1`，这句 SQL 就用这个编号去找。

项目里这周还多了一个帮手，叫 MyBatis。查回来的三列，名字正好和 `Repair` 里的 `id`、`room`、`content` 对得上，它就把这些东西放进一条 `Repair`。

这个文件通常叫 Mapper。先知道它夹在 Java 和 MySQL 中间就够了：Java 把编号交给它，它拿着 SQL 去找。

`RepairController.java` 也跟着变了：

```java
package com.example.repair;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController // Spring 得先知道，这里也能回话
public class RepairController {

    private final RepairMapper repairMapper; // 去 MySQL 找报修要用它

    public RepairController(RepairMapper repairMapper) {
        this.repairMapper = repairMapper; // Spring 创建 Controller 时，把 Mapper 放进来
    }

    @GetMapping("/repair") // 找 /repair 的，交给下面这段
    public Repair repair(@RequestParam("id") Long id) {
        return repairMapper.findById(id); // 拿编号去 MySQL 找，再交给浏览器
    }
}
```

`@RequestParam("id")` 还是第二周见过的东西。这次浏览器带来的不是名字，而是报修编号。

中间多出来的几行，是让这个 Controller 手里有一个 `RepairMapper`。Spring 创建 Controller 时会把 Mapper 交给它。先让它待在这里，不急着给这件事起更多名字。

等 Mapper 已经放进手里，Controller 要做的事只剩一句：

```java
return repairMapper.findById(id);
```

编号交给 Mapper，Mapper 去 MySQL 找，找到的报修再交给浏览器。

Spring 还得知道 MySQL 在哪里。`application.properties` 是这样：

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/after_class
spring.datasource.username=root
# 只在自己的电脑上改，别把真正的密码提交到 GitHub
spring.datasource.password=把这里改成你的MySQL密码
```

`after_class` 是第五周建的地方。

项目里还多了 MySQL 驱动和 MyBatis。没有它们，上面的 Java 和 SQL 还说不上话。完整的 `pom.xml` 放在下面，不用逐行看，只找比上周多出来的两块 `<dependency>`。
