# 第零周：先把环境搭好

电脑上准备好 JDK 17 和 Maven 3.6.3 或更高版本，项目也下载下来。

安装过程跟着教程走，或者让 AI 带着装。把你的操作系统、做到哪一步、具体报错告诉它，别只扔一句“运行不了”。

终端里试一下：

```bash
java -version
mvn -v
```

两条都能显示版本，且 Maven 显示的 Java 版本也是 17，就可以往第一周走了。

现在用不到 MySQL，也用不到 Node。AI 要是顺手列出半页安装清单，先让它停一下。

后面笔记里的命令，都在项目里放着 `pom.xml` 的那个文件夹执行。

准备好了，就去[第一周](第01周.md)。

<details>
<summary>后面说的“重新运行”，怎么弄？用到时再看。</summary>

改完代码先保存。在原来的终端按 `Ctrl+C`，再执行 `mvn spring-boot:run`。如果问是否终止批处理，输入 `Y` 回车。

等它启动后再刷新网页。光刷新网页不会让修改后的 Java 生效。
