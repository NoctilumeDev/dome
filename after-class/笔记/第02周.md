# 第二周：把名字带过来

上周留了个问题：能不能让浏览器把名字一起带过来？

如果你去查了，已经知道答案，那挺好。也不差这几分钟，一起试试，看看是不是你想的那样。

没查也没关系。学完这一小段，你也会得到答案。

上周的回话是写死的：

```java
return "你好";
```

要跟张三打招呼，当然可以改成：

```java
return "你好，张三";
```

可下一位是李四呢？总不能每来一个人，就回去改一次 Java。

来的人不确定，名字也跟着变。那就先在代码里留个位置，谁来了，就把谁的名字放进去。这个位置先叫 `name`。

现在一头有了位置，另一头还得把名字送过来。先试试：

<http://localhost:8080/hello?name=张三>

浏览器回了一句：

```text
你好，张三
```

把张三换成李四，再打开一次。

这回 Java 代码没改，也没重新运行，浏览器里的名字却变了。看来 `name` 这个位置里放谁，似乎和 `?name=张三` 有关。

先别急着下结论。把这周的代码和第一周放在一起看看，找找这次改了哪几行。

[HelloController.java](../src/main/java/com/example/repair/HelloController.java) 现在是这样：

```java
package com.example.repair;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController // 给 Spring 留个记号，不然它不知道这里能回话
public class HelloController {

    @GetMapping("/hello") // 还得写清楚：找 /hello 的该去哪里
    public String hello(@RequestParam("name") String name) { // 浏览器带来的 name，要有地方接住
        return "你好，" + name; // 把名字接到问候后面，再交给浏览器
    }
}
```

找到了吗？最上面多了一行 `RequestParam`，接名字和回话的地方也变了。

`String name` 就是刚才留出来的位置。张三来了，它里面装张三；换成李四，它里面装李四。

可 Spring 怎么知道该往这里放什么？前面还有一句 `@RequestParam("name")`。浏览器带来的是 `name=张三`，它让 Spring 从里面找到张三，再放进来。

现在再看刚才的现象：浏览器把名字带过来，Spring 找到它，再放进 Java 提前留好的位置。两头接上了。

最上面的 `import` 也多了一行，它告诉 Java 去哪里找 `RequestParam`。这行有用，只是今天先把“名字怎么进来”看明白，让它待在该在的位置就行。

跟你原来想的一样吗？一样也好，不一样也好，先看看自己原来怎么想，现在又看到了什么。

`RequestParam` 这个名字以后还会见到，不用现在背。

现在 Java 能收到一个名字了。可一条报修有宿舍号、有报修内容，后面还会有编号。总不能把它们全挤成一句话吧？

下周试试，Java 能不能把这些东西分开放好，再一起交给浏览器。
