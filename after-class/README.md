## 先拿对代码

这里的代码会一周一周往前长，所以 `main` 放的是最近写到的样子，不是第一周的样子。

如果你是后来从头开始，笔记在 GitHub 上看 `main` 里的最新版，电脑里的代码切到那一周留下的标签。比如第一周：

```bash
git switch --detach after-class-week-01
```

第二周就把最后的 `01` 换成 `02`。已有的标签都在 [GitHub Tags](https://github.com/NoctilumeDev/dome/tags) 里。

如果 Git 说本地有改动，先停下，别急着加 `--force`。先把自己改过的内容另外留好，再继续切换。标签负责留下当周代码；笔记以后还会修，所以始终看 `main` 上的版本。
